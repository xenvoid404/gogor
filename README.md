<p align="center">
HTTP client minimalis untuk Go. Hanya memakai standard library, tanpa
dependensi eksternal. Didesain dengan gaya <strong>fluent interface</strong> supaya request
disusun secara eksplisit dan mudah dibaca.
</p>
